faq:
  - q: "How do I install Core Keeper mods?"
    a: "Mods install two ways: on Steam Workshop, subscribe and the game auto-installs them; on mod.io, download the mod file and drop it into your mods folder. The Mod Compatibility Checker filters the most popular mods by platform."
  - q: "Which is better — Steam Workshop or mod.io?"
    a: "Steam Workshop is the easiest (one-click subscribe, auto-updates) while mod.io offers cross-platform installs and more niche mods. Many popular mods are available on both."
  - q: "How do I know if a mod works with my game version?"
    a: "Each mod page lists its tested version — compare it with your game version, which is shown in the main menu. The site's data baseline is version 1.3.0.6, and mods are checked against it."
  - q: "Do mods break my save?"
    a: "Mods can rarely cause issues after big updates, so back up your save before installing or updating mods. If a save stops loading, remove the mods and restore the backup."
  - q: "Do mods work in multiplayer?"
    a: "In co-op, all players need the same mods installed for the session to work properly. Make sure everyone subscribes to or installs the identical set."
  - q: "Are mods safe to use?"
    a: "Popular mods from official Workshop or mod.io pages are generally safe, but they are third-party — only install from those official sources and avoid random downloads. Some mods also require an API framework to be installed first."
