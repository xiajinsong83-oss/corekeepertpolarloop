  - q: "What is Core Keeper?"
    a: "Core Keeper is a sandbox mining adventure where you dig, explore, farm, build and fight bosses in an underground cave world. It mixes mining survival with base building, farming and combat."
  - q: "How do I start playing?"
    a: "Dig into the cave walls for stone and wood, craft a workbench, then build basic tools like a pickaxe. Follow the tutorial prompts, gather resources, set up a base and defeat the first boss Glurch to progress."
  - q: "What is the first boss order?"
    a: "The main progression bosses appear in this order: Glurch the Abominable Mass, then Ghorm the Devourer, the Hive Mother, and Malugaz the Corrupted. Each drops a guaranteed progression item."

    a: "Yes — Core Keeper supports co-op multiplayer. Host a world and invite friends, or join someone else's world to explore and fight together."
