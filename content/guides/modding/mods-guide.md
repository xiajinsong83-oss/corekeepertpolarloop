Core Keeper supports official modding through Steam Workshop and mod.io, with community content managed by the CoreLib framework. This modding guide covers where to find mods, how to install them, and the most useful quality-of-life mods.

## Where to get mods

| Platform | What it is | Notes |
|---|---|---|
| Steam Workshop | Official in-game mod browser | One-click subscribe & install; requires the game |
| mod.io | Cross-platform mod repository | Browsable online, official Core Keeper page |
| CoreLib | Community mod framework / loader | Most mods depend on it; install first |

Check the [Mods hub](/mods/) for an indexed list of popular mods and their patch compatibility.

## How to install mods (Steam Workshop)

1. Open Core Keeper, go to **Mods** from the main menu (Steam Workshop tab).
2. Browse or search a mod, click **Subscribe**.
3. Mods download automatically; enable them in the in-game mod list.
4. Some mods need **CoreLib** — subscribe to it first and enable it above other mods.

For mod.io or manual installs, drop mod folders into your mods directory (usually `SteamApps/common/Core Keeper` mod folder), then enable in-game.

## Essential quality-of-life mods

| Mod | What it does |
|---|---|
| CoreLib | Framework most mods require; adds mod config UI |
| CraftUI | Bigger crafting list, search box, easier batch crafting |
| BetterChests | Chest filtering, mass-sort, larger storage views |
| NoLensFlare / visual tweaks | Removes lens-flare effects some players find annoying |
| Minable Paving | Lets you mine decorative paving blocks for re-use |
| QuickStack | Fast inventory-to-chest stacking |

Always check a mod's **game version compatibility** — after a patch (e.g. 1.3.0.x hotfixes), mods may lag behind. Watch the [Patch Notes](/patches/) page to know when to re-check your mod list.

## FAQ

**Is modding supported officially?** Yes — Core Keeper has official Steam Workshop and mod.io integration, plus the community CoreLib framework.

**Do mods break achievements or multiplayer?** Most QoL mods are client-side and don't block achievements; server mods must be installed by the host. Check each mod's description.

**Mods stop working after an update — what now?** Patch updates (like the 1.3 Riders of the Underground line) often break older mods. Update CoreLib, then check each mod's page for a compatible release.
