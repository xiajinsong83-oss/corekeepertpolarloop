Once your base has smelters and chests, the next time sink is feeding them. This automation guide goes past the basics: how power actually travels, which machines to put on the Automation Table, and four farm layouts — ore boulders, wood, crops and mobs — that run while you explore.

## How electricity really works

Every automation machine needs a powered tile next to it (or a run of Electrical Wire). Powered machines show yellow notches on the four sides of their base.

| Power source | Full-power range | Notes |
|---|---|---|
| Electricity Generator | Up to 18 conducting tiles | The backbone of every long line |
| Lever / Pressure Plate | Up to 6 tiles | Short-range triggers; levers also pass a generator signal through |
| Kinematic Dynamo | Data待核 — verify range on wiki | Generated by player motion, no wire needed between points |
| Proximity Sensors (Explorer / Enemy) | Same 6-till behaviour as plates | Auto-trigger circuits when you (or mobs) walk near |

Rules that bite:

- Power **falls off over 5 extra tiles** after the full range — lamps dim, but drills, arms and doors still work at any power level.
- **Each machine on the line costs one power level**, same as a wire tile — daisy-chaining too many machines on one generator kills the end of the line.
- **Delay Circuits** pass along a lower-power signal; **Logic Circuits** can act as a relay and boost a weak signal back up.

## Layout 1: Ore boulder drill farm

Ore Boulders are fixed, finite spawns. Aim a ring of Crude Drills around one boulder, run a generator line to them, and you never mine a boulder by hand again.

- Place drills so each faces the boulder edge — **no two drills on the same tile**.
- Behind the drills, run a Conveyor Belt + Robot Arm into a chest, or straight into a row of Furnaces — the wiki's example smelts Scarlet Ore into bars on the spot.
- Long rows need more than one generator: count 18 tiles of full power, then place a second generator mid-line.

## Layout 2: Root Seed wood farm

Root Seeds grow wood into a random adjacent tile every 2–3 minutes, forever. The farm harvests the growth tiles, not the seed:

- Plant Root Seeds in a straight, framed line — roots refuse to grow directly beside another root, so let the first root draw the growth path before planting the next.
- Face one drill at each expected growth tile; leave the seed itself untouched.
- Extend the row, don't widen it — gaps in root growth are the failure mode, and a second main root plant planted part-way extends the reach.

## Layout 3: Fully automatic crop farm

Combine five machines into one loop (all powered from one generator loop):

1. **Sprinkler** — keeps the patch watered.
2. **Robot Farm Arm** — harvests mature crops automatically.
3. **Conveyor Belt + Splitter** — feeds half the harvest to the **Seed Extractor** (which makes seeds) and half to a collection chest.
4. **Seed Extractor output** — back onto the planted patch, so the farm reseeds itself.

Because the farm arm doesn't plant seeds, the seed-extractor half is non-negotiable — skip it and the patch slowly empties.

## Layout 4: Auto door and simple mob tech

- **Auto door**: one Pressure Plate on each side of an Electrical Door, and it opens from either direction. Swap the plates for an **Explorer Proximity Sensor + Electrical Drop Gate** for a cleaner no-step trigger.
- **Mob farm bones**: an Enemy Proximity Sensor wired to a trap or turret ring turns a narrow corridor into a kill zone; exact spawn-rate tuning for built mob farms is **数据待核** — the wiki's mob farm page details vary by patch, so test your chamber in a creative flat room first.

## FAQ

**How far does electricity travel in Core Keeper?** Full power reaches up to 18 conducting tiles from an Electricity Generator, or 6 tiles from a Lever / Pressure Plate. Power then dims over 5 more tiles; each machine on the line drops the power level by one.

**When do I unlock conveyor belts and drill automation?** The Automation Table (Crude Drill, Robot Arm, basic belts) unlocks around the Tin Workbench tier; the Advanced Automation Table (Robot Farm Arm, Seed Extractor, Item Collector, Shredder, Incinerator) needs the Octarine Workbench.

**Will drills destroy my Root Seed wood farm?** Yes — if a drill touches the Root Seed itself, it harvests the plant. Keep drills aimed at the growth tiles around the seed, and never point two drills at the same tile.
