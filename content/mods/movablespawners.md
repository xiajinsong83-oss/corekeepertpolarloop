**MovableSpawners** is a Utility mod for Core Keeper available on **mod.io**. Destroy boss summoning shrines and re-place them anywhere — convenient for building boss arenas at your base.

## What it does

- Destroy boss summoning shrines and rebuild them anywhere
- Build boss arenas at your base instead of traveling
- Great for co-op where everyone wants the kill credit

## How to install

1. In the main menu, open **Mods → Browse** (mod.io) and search for the mod, then **Subscribe**.
2. Restart the game and enable the mod in the **Mods** menu.
3. Make sure the mod's listed game version matches your install.

## Safety & compatibility

- **Version check first**: mods list their compatible game version on their page. If the game warns on launch, verify before continuing.
- **Back up your world** before installing any mod — mods can corrupt saves on rare occasions.
- **Multiplayer**: client-side QoL mods work on any server; world-altering mods should match on the host and all clients.
- Framework mods (CoreLib where required) must match the game version exactly.
