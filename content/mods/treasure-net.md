**Treasure Net** is a Fishing mod for Core Keeper available on **Steam Workshop**. Fishing nets can haul in treasure as well as fish — enable treasure mode for mod-exclusive bonus items.

## What it does

- Fishing nets haul treasure as well as fish
- Enable treasure mode for mod-exclusive bonus items
- Configurable per resource type (fish/kelp/loot/treasure)

## How to install

1. Open the **Steam Workshop** page for this mod and click **Subscribe** — the game installs it automatically on next launch.

## Safety & compatibility

- **Version check first**: mods list their compatible game version on their page. If the game warns on launch, verify before continuing.
- **Back up your world** before installing any mod — mods can corrupt saves on rare occasions.
- **Multiplayer**: client-side QoL mods work on any server; world-altering mods should match on the host and all clients.
- Framework mods (CoreLib where required) must match the game version exactly.
