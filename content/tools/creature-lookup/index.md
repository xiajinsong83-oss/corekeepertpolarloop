The Core Keeper **creature lookup** is a fast reference for every regular mob — health, damage, drops and where it spawns. Type a name to filter the list instantly.

## How to use

Type in the search box to filter creatures by name. Each card shows biome, HP, damage, drops and a quick tactical note.
