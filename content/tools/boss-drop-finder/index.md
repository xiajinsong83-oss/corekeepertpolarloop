## What it does

Search any Core Keeper boss to see its drop table, drop chances and how to summon or unlock it.

## How to use

1. Select a boss (e.g. Glurch, Ghorm, Hive Mother, Azeos, Omoroth, Ra-Akar).
2. Review the drop table, chances and unlock conditions.
