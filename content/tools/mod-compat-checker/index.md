## How to install Core Keeper mods

Core Keeper mods ship on two platforms:

| Platform | How it works | Best for |
|---|---|---|
| **Steam Workshop** | Subscribe in the Workshop and the game auto-installs | One-click, auto-updating |
| **mod.io** | Download the mod file and drop it into your mods folder | Cross-platform, more niche mods |

Always back up your save before adding mods, and disable mods after big game updates until they're confirmed compatible.

## Tips for a stable mod setup

- **Check compatibility per patch** — game updates break mods; the mod page always lists its supported version.
- **Start with one mod** — confirm each works before stacking, so you can isolate crashes.
- **Read the requirements** — some mods (like API frameworks) must be installed first.
- **Multiplayer note** — all players need the same mods for co-op sessions.

## FAQ

**Are mods safe?** Mods are generally safe but are third-party — install only from the official Workshop or mod.io pages, never from random downloads.

**Do mods disable achievements?** No — Core Keeper doesn't gate achievements behind mods, but check each mod's page for its own notes.

**How do I know if a mod works with my version?** Each mod page lists its tested version. Compare it with your game version in the lower-left corner of the main menu.
