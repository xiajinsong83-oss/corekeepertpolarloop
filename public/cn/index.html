护核纪元 · 中文专区

《护核纪元》 是像素洞穴生存沙盒《Core Keeper》的官方国区中文名。本专区汇总国区发行渠道、官方中文资源与中文社区入口，并引导你使用本站的全部中文工具与图鉴。

游戏是什么

《护核纪元 / Core Keeper》由 Pugstorm 开发、Sold Out 发行，是一款 1-8 人联机的洞穴挖矿生存沙盒：你在神秘地下世界苏醒，采集矿石、搭建基地、种植烹饪、挑战 Boss，并一步步向世界深处推进。Steam 好评如潮，中文社区活跃。

FAQ

护核纪元与 Core Keeper 是同一个游戏吗？ 是。《护核纪元》是 Core Keeper 的官方国区中文译名，版本与全球版同步更新。

国区玩家能联机吗？ 可以。游戏支持 1-8 人联机，国区与全球玩家均可通过邀请码加入同一世界。
