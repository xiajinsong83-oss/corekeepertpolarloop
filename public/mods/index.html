Mods

Core Keeper mods are supported on two official platforms only: Steam Workshop and mod.io. The official modding SDK and Steam Workshop integration are currently in beta — install with version checks.

Steam Workshop

官方支持的模组平台，游戏内订阅，重启后生效，关闭游戏时自动更新。

  1. 在 Steam 创意工坊浏览 Core Keeper 模组（建议按 Trending/最新排序）
  2. 点击订阅需要的模组（注意看作者标注的游戏版本兼容）
  3. 重启 Core Keeper 使模组生效；更新会在游戏关闭时自动拉取
Open Steam Workshop →

mod.io

官方支持的跨平台模组库，网页订阅或游戏内 MODS 菜单安装，关闭游戏时自动更新。

  1. 访问 mod.io/g/corekeeper 浏览模组（使用版本过滤器筛选当前游戏版本）
  2. 点击订阅；或直接在游戏主菜单的 MODS 界面浏览订阅
  3. 阅读模组描述，安装其声明的依赖后再启用；重启游戏生效
Open mod.io →

Important notes

  • 官方仅支持 Steam Workshop 与 mod.io 两大平台，其他第三方平台（如 Thunderstore、Nexus Mods 上的历史 Core Keeper 板块）多已停更或废弃，且不受官方支持——安装前请以 modding.corekeepergame.com 官方说明为准。
  • 安装模组前务必核对模组标注的游戏版本（当前站点追踪版本 1.3.0.6）；版本不匹配的模组可能导致存档或联机异常。
  • 官方文档不包含 CoreLib：部分社区模组会要求 CoreLib 作为依赖，是否使用请以具体模组描述为准。

Best Core Keeper mods — FAQ

Where do I install mods from? Only two official platforms: mod.io (in-game browser) and Steam Workshop. Thunderstore is deprecated and Nexus Mods is effectively abandoned for Core Keeper — avoid outdated copies.

Which mods are safe for 1.3? mod.io lists the compatible game version on every mod page. Framework mods (CoreLib) must match the game version — if a mod warns on launch, check the version before continuing. Back up your world before installing any mod.

Do mods work in multiplayer? Many client-side QoL mods (autofish, health bars, placement) work on any server. Mods that change world content should be installed by the host on both sides. When in doubt, test on a single-player world first.
